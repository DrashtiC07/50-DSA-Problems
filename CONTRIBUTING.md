# Contributing to 50 DSA Problems

Contributions, alternative optimal solutions, and test cases are welcome!

## How to Add or Improve a Problem

1. **Format:** Every problem folder should follow the structure:
   - `solution.py` (optimal, documented Python 3 code with test assertion blocks).
   - `notes.md` (intuition, edge cases, step-by-step approach, time & space complexities).
2. **Coding Standards:**
   - Use clean, idiomatic Python 3 typing (`from typing import List, Optional`).
   - Add inline comments for non-trivial logic.
   - Run and verify all test assertions before opening a PR.

## Maintainer Responsiveness SLA
We aim to review issues and pull requests within **24 hours**.
