## 📌 Overview

A curated, interview-focused repository covering **50 foundational and high-frequency Data Structures & Algorithms problems**. Each problem includes:
- **Optimal Python Solution:** Concise, idiomatic implementation.
- **Detailed `notes.md`:** Intuition, edge case walkthroughs, and alternative approaches.
- **Complexity Analysis:** Explicit Big-O Time and Space metrics.
